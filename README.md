# TextUtils-1st-React-App

TextUtils is a React-based text utility application that allows users to manipulate and analyze text.

## Features

- Convert text to Uppercase
- Convert text to Lowercase
- Remove Extra Spaces
- Copy Text to Clipboard
- Character Frequency Analysis
- Dark Mode Support

## Technologies Used

- React.js
- Bootstrap
- JavaScript
- HTML/CSS

## Run Locally

```bash
npm install
npm start
```
